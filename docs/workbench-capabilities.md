# 当前工作台能力与边界

当前唯一客户端为 Tauri 工作台。下列能力依据现有代码与专题文档整理；自动回归通过不等同于全部真实数据、服务和人工操作已验收。

| 能力 | 当前实现 | 详细说明 |
| --- | --- | --- |
| 参考线 | 本地矢量、连接来源、人工绘制、活动路线选择与顶点编辑 | [路线选择](route-selection-workflow.md)、[属性表](route-attribute-table.md) |
| 横断面 | 左右不对称、逐车道宽度、隔离带、应急车道、路肩、边坡水平投影；手动或字段映射 | [引擎协议](engine-interface.md) |
| 多路线生成 | 已加载的参与路线分块计算，保留部件标识、进度、取消、人工覆盖及缓存 | [批量生成](source-batch-generation.md) |
| 道路面编辑 | 部件宽度、顶点编辑、删除恢复、撤销重做与输入版本校验 | [成果编辑](generated-surface-editing.md) |
| 设施 | 模板目录、实例快照、人工布设、编辑，以及基础沿线示意布设 | [设施资源](facility-assets.md) |
| 地图与影像 | MapLibre 图层、底图选择、本地定位影像的视口瓦片、显示副本 | [GIS 适配](maplibre-gis-adapter.md)、[显示性能](map-render-performance.md) |
| 工程与导出 | schema 2 JSON 保存恢复、旧 schema 1 兼容、WGS84 GeoJSON 和工程 CRS GeoPackage | [架构](architecture.md)、[部署](maplibre-native-runtime.md) |
| 验证 | 单元、格式、静态检查、自动桌面回归及可选独立 GIS 校验 | [开发验证](development.md) |

路线传输页大小和单块计算资源限制不是整体路线或顶点的固定数量上限。支持分页的来源默认续读到末页，允许停止和继续；只有确认加载才写入地图。有界快照来源明确显示能力边界，不能冒充完整来源。

每条路线仍采用固定横断面；业务断链、区间变宽、复杂路口、真实桥隧层级、地形边坡、影像配准和 AI 提取尚未形成完整生产能力。倾斜视图不代表工程三维，参数化设施不代表规范设计。

矢量及成果目前仍有完整内存副本。空间索引与按视口查询的工程持久化、超大数据基准、独立安装器及干净 Windows 部署属于待完善事项。历史版本的数量、耗时与通过项只对其当时样本有效；现行证据见 [路线恢复记录](tauri-route-restoration-20261007.md)。
