# 2026-10-03 定时系统审查

## 范围与方法

从干净工作区和现有 Tauri + React + MapLibre + Rust 实现开始，保留用户正在使用的窗口。另开独立 WebView2 配置的审查实例，实际鼠标滚轮操作，并通过真实桌面 WebView2 的 CDP 输入进行可重复回归；文件对话框仅替代所选路径，不替代 Rust、GDAL、PROJ 或几何结果。沿用原版六组菜单及数据入口对照检查。

## 发现与改进

- 普通鼠标滚轮已可缩放。本轮补充精细像素滚动/横向双指滚动平移，以及 Ctrl 标记的触控板捏合缩放；捏合围绕指针位置，阻止 WebView 页面误缩放。普通离散滚轮仍由 MapLibre 处理。浮层事件不接管，拖点时忽略滚轮，避免坐标跳变。
- 顶点模式原先单击直接删点，改为选中并高亮，Delete 或工具栏显式删除，可撤销；保留至少两个控制点。右键不再启动拖点，窗口外松开或失焦恢复平移，切换工具清理拖点状态。
- 绘制和顶点模式关闭双击缩放，绘制双击只加入一个点；返回平移恢复双击缩放。路线新增点状态提示修正计数。
- 菜单弹出后支持左右键切换、Tab 收起，执行命令前将焦点交回入口；长菜单限制视口高度并独立滚动。
- 数字输入滚轮时退出编辑，防止表单滚动意外改变业务参数。
- 小于 1180px 的初始窗口收起工程属性面板；从宽窗口缩小时，无选中设施则收起。保留手动展开、设施属性入口，扩大主地图区域。不自动隐藏正在查看的设施。
- 地图缩放与指北按钮提示改为中文。
