# 多数据源与图层映射设计

当前连接流程已改为会话认证复用、浏览 Schema / 空间表、添加图层后再读取，见 [数据连接与路线图层流程改造](connection-source-flow-20261003.md)。数据库支持范围见 [多空间数据库数据源](spatial-database-sources-20261003.md)。下文保留各轮实现和验证记录。

## 使用流程

数据源连接成为紧凑选择区：先选择命名连接，再选择已配置路线图层；按偏好恢复已保存密码，或输入本次密码后读取。管理窗口采用连接列表与编辑区布局，支持 PostGIS / WFS 连接的新建、编辑、复制、删除；同一数据库可配置不同 Schema/表，图层可单独编辑和删除。连接类型在创建后固定，避免切换类型意外丢弃整组图层。名称冲突和重复图层会提示。长表单可滚动，保存区域保持可见，Escape 关闭后回到管理入口。

公开连接配置存入本机 WebView2 配置库，不加入工程连接凭据；白名单可保存 `rememberPassword` 偏好，旧配置缺少该字段时默认记住密码。Windows 上密码由 Windows Credential Manager 加密保存，服务名为 `com.roadgeometry.lujing.database`，凭据 ID 为连接 UUID，内容是包含 `identity` 和 `password` 的 JSON。应用启动后按 UUID 取回，并核验身份后才复用。含用户名、密码或令牌参数的 WFS 地址禁止保存。数据库/服务配置变更时清除旧图层规则及旧身份凭据，旧工程仍保留自己的数据与映射。

管理窗口保存时可写入当前提供的密码；数据库连接认证成功时也会写入。关闭记住密码会删除已保存凭据，当前进程中的密码仍可继续使用。复制连接生成新 UUID，不继承原凭据；删除连接时清理对应凭据。记住密码偏好不属于连接认证身份，身份由数据源类型和公开连接参数决定，名称及图层变化不改变身份。此策略不表示 Credential Manager 生命周期、重启恢复或独立安装器已经完成验收。

## 映射范围

字段映射是独立的业务转换步骤，不绑定整个数据库。复用规则保存于“连接 ID + 图层 ID”，同时检查数据库/服务、Schema、表/要素类型和几何列指纹。同名表处于不同 Schema 的规则隔离。项目继续保存实际应用的字段映射和非敏感来源标识；连接或图层被删除后，工程成果不会随之删除。规则保存本身不改变输入版本和几何结果。

自动识别通过显式按钮应用；从字段名候选匹配，不推断实际道路宽度。数值映射继续遵循原有范围与空值规则；读取其他来源不继承当前数据库规则；不存在的源字段解除映射并提示复核。本地文件使用同一字段映射界面，独立于连接配置库；本地多图层文件使用文件路径和图层名标识来源，避免不同表混用字段规则。

## 验证与限制

前端包含连接序列化、密码排除、多个数据库恢复、不同 Schema 映射隔离、目标变化拒绝写回、WFS 认证地址拒绝保存及损坏配置不被读取覆盖的测试。桌面回归实际操作多连接/Schema图层新增、复制、删除、管理窗口焦点，使用项目属性样本验证自动识别及按图层保存；Rust/GDAL 导入导出继续用真实后端回归。远程生产服务器未提供有效连接，未声称在线连库验收完成。

当前图层目录为手动登记的可复用配置，尚不自动枚举远程数据库的全部 Schema/表。连接配置属本机应用设置；工程携带应用后的映射和来源标识，不携带连接库或密码。

回归脚本原先固定等待 300ms 再读取旧项目迁移的保存文件，出现偶发读取旧版本。本轮改为等待 UI 保存完成状态，再检查文件；保存后端未变。

## 数据库 / Schema 连接与独立测试

连接配置与路线表分开：新建 PostGIS 连接可选择整个数据库或指定 Schema，不要求表名或几何列；WFS 服务连接不要求要素类型。连接可不含任何图层，保存后按需添加。点击连接编辑基础配置，点击其下图层编辑读取目标；字段映射仍按图层保存，不扩展为整个数据库的统一映射。默认数据库范围保持旧配置指纹兼容，不因默认字段加入而清除旧映射。

管理窗口增加独立“测试连接”，与“保存连接”并排。测试不要求连接名称或路线表，不自动保存、不导入、不清理工程成果。Rust 在后台通过只读 GDAL/OGR 测试：PostGIS 查询常量；Schema 范围额外检查存在性及 USAGE 权限；WFS 打开服务元数据。界面显示测试中、成功或失败，修改配置后清除旧提示。失败错误不回显密码或连接串，密码仍只用于当前会话。

当前测试不代表已具备目标表的 SELECT 权限、空间列或 CRS；这些仍在实际读取图层时检查。未提供有效生产库连接，生产库成功认证及 Schema 权限分支仍未实测。图层仍手动登记，尚不支持自动枚举全部表，也不会批量导入整个数据库。

## PG 连接类型与可定位诊断

数据库入口明确为 PostgreSQL（PG，支持 PostGIS）；PostGIS 是空间能力而不是另一个连接协议。数据库类型列表标明 MySQL / MariaDB、SQL Server、Oracle 暂不支持，避免使用 PG 参数假装连接其他数据库。已有内部 `postgis` 类型保持兼容，列表显示为 PostgreSQL。

测试查询返回一行诊断属性，分别确认数据库连通、PostGIS 扩展、Schema 存在性和 USAGE 权限。普通 PG 缺少 PostGIS 时仍显示连接成功，并提示读取 geometry 空间表的扩展要求。此前底层 stderr 被统一替换成笼统错误；现改为只输出不含凭据的错误分类：认证、数据库不存在、DNS、网络/端口、SSL、pg_hba.conf 或权限。增加关闭 SSL 选项；默认仍使用 prefer。早期回归仅覆盖本次会话复用；跨重启记住密码是新增流程，需按下述边界单独验收。

真实回归使用单独初始化的本机 PostgreSQL 9.6 测试实例（127.0.0.1:55439、独立 artifacts 数据目录），未修改用户已有服务、库、网络配置或窗口。真实校验普通 PG 正确密码成功、错误密码失败、SSL require 对无 SSL 服务器失败、disable 成功、public Schema 可访问及缺失 Schema 提示。只读测试不导入业务数据。测试实例执行完成后已停止。该旧版本仅用作现有本机回归资源，不代表推荐的生产版本。

## 密码持久化验收建议

以下是新增功能应覆盖的验收边界，尚不能由上面的历史测试结果代替：

- 新建连接默认记住密码；移除 `rememberPassword` 字段的旧连接也按开启处理。关闭后应持久化偏好，并清除该连接已保存的凭据。
- 仅将凭据写入 Windows Credential Manager 的指定服务与连接 UUID 项；localStorage 只包含偏好，不含密码，工程文件和日志、错误状态、来源指纹均不含密码。
- 保存窗口中提供新密码时应写入凭据管理器，即使此时尚未验证服务器认证；连接认证成功后也应写入。UI 不得把“已保存凭据”显示成“连接成功”。若认证失败，应允许用户替换密码，并检查错误信息不回显密码。
- 应用重启后，仅当存储的 `identity` 与当前公开连接身份相符时恢复密码。修改连接参数后清理旧凭据并要求重新输入；只改名称或图层不应让凭据失效。
- 复制连接必须分配新 UUID 且不读取/复制原凭据；删除连接须删除凭据。关闭记住密码后，本次运行仍可使用已加载到内存的密码，应用退出再启动时要求重新输入。
- 覆盖凭据不存在、读取/写入/删除失败、身份 JSON 损坏、用户取消记住密码及无密码认证等路径；界面需允许本次会话继续或清楚报告不能持久保存，不得静默写回公开配置。
- 验证应在支持的 Windows 桌面环境执行，并检查实际 Credential Manager 条目生命周期。不要据此宣称已连通真实公司数据库；独立安装器和干净 Windows 安装仍需作为单独部署验收。

本次密码持久化已完成 Windows 实机验证：37 项前端测试、30 项常规 Rust 测试及额外 1 项原生凭据往返测试通过，最终桌面回归 81 项通过，浏览器错误 0。独立脚本验证 UI 保存后在第二个真实桌面进程自动恢复，并检查清除、身份隔离和配置写入失败保护，合成凭据已清理；详细报告与部署边界见 [连接读取流程说明](connection-source-flow-20261003.md)。管理窗口的测试连接仅验证，编辑的新密码需保存连接后才持久保存。
