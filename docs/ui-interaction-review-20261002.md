# 桌面 UI 与交互复查（2026-10-02）

## 复查方式

在独立 WebView2 配置目录启动实际 Tauri 桌面程序，使用 computer-use 操作窗口，再通过 WebView2 调试接口运行可重复的操作检查。测试采用示例路线、合成栅格及测试设施，不覆盖用户项目；截图、测试输出与日志留在忽略的 `artifacts` 目录。

检查常规桌面窗口及 1024×720 布局。重点覆盖地图工具、浮层、弹窗、左右面板、设施编辑及生成/保存/导出闭环。

## 已修正的问题

| 区域 | 复现问题 | 调整结果 |
| --- | --- | --- |
| 地图工具 | 多个浮动工具盒分散，窄画布依赖固定高度避让 | 合并为顶部工具带，宽度不足时自然换行 |
| 摘要与图例 | 绘制时重新展开摘要，提示条盖住摘要内容 | 摘要与图例使用网格，提示和对比提示位于后续行 |
| 主显示空间 | 左右面板分别收起，需要多次操作 | 增加“专注地图”，一次收起两侧；恢复时保留进入前的组合 |
| 底图选择 | 左下按钮打开右上面板，关联不直观 | 面板锚定左下按钮上方，宽度和高度受画布限制 |
| 底图关闭 | Escape 关闭后仍显示“已退出绘制”，并切换绘制状态 | 弹出层单独处理 Escape，保留当前工具和状态；支持点击外部关闭 |
| 地图右键 | 靠近边缘时裁切，路线模式也出现区域设施命令 | 自动限制到画布边界内；按当前工具显示命令，未满三点的区域不能完成 |
| 右键键盘操作 | 缺少独立关闭和命令导航 | 支持方向键、Home/End、Escape；关闭菜单不退出当前绘制工具 |
| 模板菜单 | 编辑弹窗关闭后仍保留菜单；列表底部菜单可能裁切 | 选命令后收起、点击外部或 Escape 收起；底部菜单向上展开 |
| 模态表单 | 初始焦点落在关闭按钮；长内容标题和操作区一起滚走 | 优先聚焦编辑字段，标题固定、内容独立滚动、操作区保持可访问 |
| 底图署名与比例尺 | 署名被隐藏，比例尺与底部状态区位置不协调 | 恢复可见署名，移至生成按钮上方并避让缩放控件；同步调整比例尺位置 |
| 桌面检查 | 调试端口可能先暴露空文档；新增地图源尚未渲染时旧检查即通过 | 等待工作台页面，并在联网检查中等待数据源加载与地图 idle |

## 复查边界

WFS/PostGIS 的界面入口与字段映射已检查，未使用真实生产服务器和凭据验证连接。此次未增加真实三维、影像识别或配准能力，也不代表完成大规模数据性能基准。倾斜视角仍是二维成果的视角示意。

在线截图只代表当次视口请求成功，不保证公共服务后续可用性或数据位置精度。工程几何与显示底图的坐标关系沿用现有处理。


## 标注区域的布局细化

- 导航项与面板标题压缩高度；标题按钮只收起当前面板，属性面板由地图工具栏控制。
- 数据导入卡片改为紧凑的图标与文字布局，保留支持格式和导入入口；打开、保存统一至顶部，避免重复操作。
- 项目详情默认折叠，展开仍能查看格式、工程 CRS 和输入版本；远程连接与字段映射入口保留。
- 地图路线摘要收窄；生成区只保留状态与主要操作，取消及未就绪提示沿用原逻辑。
- 底图目录限制为 400 像素以内，标题与来源切换共用一行，选项分两列；离线画布与本地影像并列，坐标提示及完整来源说明随选项显示。
- ArcGIS 令牌不占用普通底图列表空间；仅在选择令牌服务但未提供凭据时出现输入和应用按钮。凭据仅保留当前会话。
- 坐标栏切换 WGS84 经纬度或工程 XY 米制显示，与状态反馈合并为一行；完整操作反馈保留悬停提示。

新增桌面检查覆盖数据入口去重、项目详情折叠、坐标切换、底图目录高度与缺令牌展开；截图 `20-data-workspace.png`、`21-compact-basemap.png` 用于复核宽窗口主显示区域。


## 道路信息分组与单侧断面修复

道路面板按横断面、成果显示、沿线布设三个页签组织，保留已填参数及原有操作；横断面汇总的计算组成移至提示，重复的车道序号说明精简，单次复制左右配置按需展开。

横断面示意不再将参考线固定在视口中间。先按总宽度确定比例，再将完整断面居中，参考线根据左右宽度差移动；几何计算和实际横断面参数不变。桌面回归检查仅左侧、仅右侧、极端不对称和宽隔离带，验证每个组成带均位于 SVG 范围内及参考线位置符合左右宽度；包括超过业务宽度上限但仍需完整展示的问题输入。

截图 `22-one-sided-section.png`、`23-along-route-tab.png` 用于复核单侧显示和道路分类；`21-compact-basemap.png` 复核紧凑底图列表与单行状态栏。此轮累计 60 项桌面检查，包含实际 Rust 生成、导出与在线瓦片显示。


## 紧凑标题与显示材质即时更新

左侧标题原始 `height: 67px` 未被后续 `min-height` 覆盖，本轮显式将固定高度与最小高度设为 36px，减少标题和页签间距。

路面材质是显示选项，移出道路输入失效判断；切换材质或整体/分组表达仅更新地图绘制，保留原有成果和输入版本，并继续记录项目的未保存状态。真实路线和横断面编辑仍会清除过期成果。生成过程中的输入一致性校验同步沿用此边界。

沥青、混凝土、碎石使用不同配色及固定种子的 64×64 细颗粒纹理；整体路面显示纹理，分组成果显示分类颜色。纹理按缩放级别淡入，远景不干扰地图查看；每个地图样式最多保存三个小纹理，成果清理同时删除材质叠加层。此为二维显示材质，不改变几何、宽度或已生成属性快照，不代表真实影像或三维物理材质。

新增桌面回归在三种材质、两种表达间切换，核对生成结果完整内容与输入版本不变、地图绘制属性即时更新及标题高度；原有路线编辑清理测试同时覆盖纹理层清理。累计 61 项桌面检查通过，截图 `24-live-pavement-display.png` 展示实际地图与紧凑标题栏。
