# 来源无关的空间数据访问改造

## 产品定位与边界

定位为本地优先的道路几何生产工具，而不是 PostGIS 客户端。PostGIS、文件、GeoPackage 和空间服务是输入适配器；道路引擎只接收明确 CRS 的参考线和业务属性，不接收数据库连接或认证参数。工程继续优先采用 GeoPackage 配合外部影像，不要求安装数据库服务。

不是所有来源都有 SQL、主键、字段注释、快速计数或随机分页。统一交互与数据契约，保留来源能力差异；不能把前 500 条的筛选当作全数据筛选，也不能静默忽略不支持的条件。

## 分阶段实施

| 阶段 | 改造范围 | 验收条件 |
| --- | --- | --- |
| 一：统一矢量入口（本轮） | 来源描述与能力模型；文件、GeoPackage、SQLite、PostGIS 共用查询命令与属性表；其他连接明确有界快照；左侧文件/连接入口并列 | 不安装 PostGIS 时完成文件/GPKG 查询、跨批勾选、地图显示和活动参考线选择；全字段与几何保留；超过旧 2,000 条上限的数据可查询；不支持的条件明确拒绝 |
| 二：规模化访问 | 本地索引/工程缓存；稳定键分页或游标；按稳定 ID 获取所选完整要素；地图范围加载与属性读取分离 | 记录硬件、数据规模、冷/热缓存、耗时、峰值内存和交互延迟；未显示的数据不丢失；不同来源的失败/取消可恢复 |
| 三：大路网显示与生产 | 显示副本分级简化/矢量瓦片；按路线/区间调度；完整几何精确生成 | 显示简化不改原始成果；批量生成可追溯、有进度/取消；生产数据库与文件代表样本验收 |
| 四：影像与混合输入 | 沿用独立栅格瓦片、配准、人工边界与后续 AI 能力 | 不将栅格强行套进矢量属性表协议；影像精度、推定与人工确认分别记录 |

不在本轮增加用户数据库索引、导入整表到前端、重写 GIS 渲染器、引入云服务或第二套道路几何引擎。

## 第一阶段契约

统一命令 `query_vector_data(source, query)`：

```typescript
source = { type: 'file', path, layer_name }
      // 或
source = { type: 'connection', connection: { kind, ... } }

query = { expression, limit, offset, bbox? }
```

`bbox` 为 WGS84 `[west, south, east, north]`；输出 `collection` 是 WGS84 地图/源路线交换副本，保留源 CRS 声明。业务生成仍转换到适合区域的投影米制坐标；工程 GeoPackage 输出保留业务 CRS。

查询结果包含完整业务字段、字段注释（来源提供时）、几何、源 CRS、本批条数、批量大小、偏移、是否有后续记录、已应用条件、分页警告与能力。能力明确区分来源级查询与已读快照，并单独描述分页、属性条件、空间范围、原生方言与稳定排序。

前端入口与属性表消费统一结果，不用 `kind === 'postgis'` 决定是否展示高级读取功能。适配层负责转换安全通用表达式，后台根据能力下推筛选；底层方言差异不得泄漏为“所有来源完全相同”的承诺。

## 交互原则

- 左侧“路线数据”提供文件与连接两种入口；没有保存连接时首先展示离线文件入口。当前入口只保留一个主要动作，低频管理与认证折叠。
- 来源级查询与“本批筛选”分开，明确告知作用范围。没有来源查询能力时只显示快照限制，不提供假翻页。
- 字段按列展示，可选择显示列；隐藏列不删除属性。字段注释可空，后续阶段增加可保存的业务别名。
- 本地安全表达式不是任意 SQL，原生 SQL 高级模式另行评估权限、方言、类型与安全边界，不在本轮伪装为已实现。
- 来源查询不同条件会清空跨批勾选；同一条件翻批保留选择。批量上限与选择上限明确，错误条件保留上次有效结果。
- 属性表、批次/表内分页与确认按钮分区；小屏下可折叠高级条件，不让确认按钮覆盖分页或表格。

## 正确性与性能约束

只读查询、有界工作线程和输出大小/超时限制；源文件不覆盖。尽量先筛选再 LIMIT，用 LIMIT+1 判断后续记录，不为显示总数扫描整表。文件中的查询并不自动获得空间/属性索引，普通 GeoJSON/SHP 的深分页可能重新扫描；不能把“前端每批 500 条”视为数据库或文件扫描工作量的保证。

有可用稳定键时排序；没有稳定键时明确警示。分批请求不是固定事务快照，源数据变化可导致重复/遗漏；第三阶段前不声称稳定读取任意持续变化的全表。恢复读取能力、固定快照和缓存失效检查在第二阶段解决。

连接凭据仅在会话/系统凭据管理器及 native 调用中出现，不进入标签、工程原始属性、日志或生成请求。保留现有连接 v1 配置与来源映射指纹。

## 验证计划

文件和 GeoPackage 使用隔离合成 3,000 条路线，验证来源级 left/right 筛选、超过 2,000 条读取、末批 has_more、全部字段/中文值/FID/多部件保留、bbox 与 WGS84 转换、注入拒绝和错误不破坏现有结果。真实桌面验证文件/连接切换、跨批勾选上图、字段映射、隐藏列、地图点击和小屏按钮可访问。

PostGIS 用既有隔离合成测试库复验；不接触生产库。前端 TypeScript/单元测试/格式、Rust fmt/test/Clippy 通过后构建真实 Windows 便携程序并创建中文 Git 提交，不自动推送。
