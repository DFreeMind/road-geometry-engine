# 数据面板：连接优先

> 历史改进记录：本文的实现状态、数量上限、部署路径与验证结果对应文件名标明的日期。当前技术架构和能力边界见 [架构](architecture.md) 与 [能力清单](workbench-capabilities.md)。

依据用户要求，将 WFS / PostGIS 从面板下方的折叠入口移到顶部，默认展开 PostGIS 数据库。取消重复的“连接路线数据源”标题，将类型切换移为整行按钮。主表单显示主机、数据库、路线表及用户/密码；端口、Schema、几何列和 SSL 按需展开。WFS 主表单显示地址和图层，版本与分页按需展开。切换来源保留两边草稿；读取期间禁用表单和来源切换，提交使用原生必填与范围校验，高级字段无效时展开对应区域。

本地路线文件、栅格影像、人工绘制归为紧凑的“其他输入方式”，保留当前路线、字段映射和项目详情。未改动 GDAL 数据读取协议、坐标转换及业务几何；密码仍仅用于连接，不写入项目。连接成功只清理密码。

验证：TypeScript、21 项前端测试、全目录 Prettier 和桌面构建通过；桌面回归加入数据源置顶、默认 PostGIS、高级设置、切换草稿保留及紧凑宽度检查。复核 WFS / PostGIS 窄窗口和宽窗口主工作区截图。第一次回归在 GeoPackage 导出等待阶段超时，复测完整通过；没有改动导出后端。真实远程服务器没有提供可用连接，未将 UI 回归视为生产数据库连接验收。
