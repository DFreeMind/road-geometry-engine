# 路面成果编辑与设施显示

## 编辑对象与范围

地图工具栏和“道路”菜单提供独立的“编辑路面成果”。点击生成的面后，左侧显示所属来源、记录及线部件，支持左右逐车道宽度、隔离带、应急车道、路肩和边坡水平投影宽度修改。参考线顶点工具仍仅编辑参考线，不与成果编辑混用。

宽度修改调用现有 Rust 引擎精确生成当前线部件，校验和投影准备在后台线程执行，不重新计算整个来源。计算成功且工程未发生变化时，规则和成果作为同一个可撤销编辑提交；取消、失败或迟到结果均不覆盖原成果。

“删除选中组成”以组件、左右侧和车道序号匹配；“删除此路段成果”排除当前线部件的全部成果，包括其自动附属成果。删除需确认，不修改原始参考线、原始属性或保存的引擎响应。地图和 GeoJSON/GeoPackage 导出使用同一过滤规则，后续重生成仍遵守已保存的排除规则。

来源映射依然针对整张表；人工宽度覆盖仅作用于所选记录的线部件，优先级为“部件覆盖 → 记录覆盖 → 来源字段映射”。其他部件的输入签名与成果不受本次宽度修改影响。手动路线支持同样的宽度修改和成果排除。

撤销/重做恢复规则和成果；“恢复此路段原规则”清除当前部件的宽度覆盖与成果排除并重生成，保留原始参考线及其他部件编辑。关闭编辑面板后，“道路”侧栏的“已保存的路面编辑”仍可打开已经被全部删除、无法地图点击的路段，重开工程后同样可恢复。

本轮不是任意多边形边界编辑器：尚不提供面顶点自由拖动、任意裁切线或按桩号切出新编辑区间。宽度修改作用于所选线部件的完整横断面，不把地图显示简化结果反写为生产几何。

## 设施符号

点设施图片符号原本约 14 像素；现按 zoom 分级显示，默认倍率 1.3，在常用近景约 31–38 像素。设施侧栏可调 0.75–3 倍并重置，倍率随工程保存。自动生成的点设施标记也随 zoom 和倍率调整。

此倍率仅调整屏幕符号，不改变设施坐标、真实尺寸、规格和道路生成输入；低 zoom 图片符号隐藏，避免大量图标遮挡。线和面设施仍以真实几何显示，不将符号大小伪装成地理尺寸。
