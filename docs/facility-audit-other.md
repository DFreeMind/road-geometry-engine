# 监控与检测、通信与收费、排水与配套、其他附属设施复核

复核范围：`tools/facility-assets/facility_catalog.py` 的四个分类，共20项。按 `FAMILIES` 顺序逐项核对默认几何；按 `facility_icons.py` 中同序 `d` / shape path 核对符号。图标均为应用自绘的抽象黑白 SVG，不是标准图例复刻。目录注释已说明这些是检索与示意模板，规格待填，不代表工程设计或规范校核；本复核补充图层应表达的对象、定位输入与缺口。

证据等级：**正文**=可读官方标准正文直接支持设施/布设要求；**官方指引**=官方发布的设计/建设指引或规范条文；**仅元信息**=官方标准公告/标准信息平台能核版本、状态、范围，但未据其全文确认具体条款；**未取得**=未找到足以支持设施级合规判断的官方公开正文。标准链接优先交通运输部、国家标准信息公共服务平台及政府网站。涉及地域性道路和城市排水的标准不能泛化为全国性条款。

## 对实现的整体结论

1. 图标是识别性符号，不是规范图例：每个SVG都应标为“示意符号/非比例符号”，并避免借图标形状暗示构造已满足标准。
2. 默认几何可以承载台账位置，不足以表达工程设施整体：Point 适用于多数设备锚点，但收费/ETC门架、限高架需跨路对象；排水沟需要纵断面/断面；减速丘需要面及高程剖面；避险车道需构成分区及纵断面。应区分设施的资产点位、设计对象与影响/服务范围。
3. 排水节点必须补高程和拓扑：雨水口、检查井、管线井都要区分地面/井盖高程、井底/管底标高与连接边；只有平面点和直径/深度不能做流向、坡度或积水校核。
4. 布设不应默认规则化：摄像机、气象站、交通检测器、通信节点和凸面镜需有目标/覆盖/遮挡/链路或观测代表性输入；紧急电话、里程牌/百米桩的间距位置应依据路线与现行项目标准/方案；不得从空的 `spacing_m` 推定全国统一间距。
5. 规范版本：本次可确认JTG D81—2017和JTG/T D81—2017由交通运输部2017公告发布并自2018-01-01施行；JTG/T D33—2012由部公告发布；JTG/T 3381-04—2025已于2026-03-01生效；GB/T 33697—2017在国家标准平台标示现行且复审继续有效。对只有标准体系目录的细分通信/调查设备标准，文中明确是元信息，不据此杜撰条款或声称全文现行状态已逐项复核。GB/T 47464—2026准确名称为《城市道路交通信息监测和显示设备设置规范》，截至本复核日尚未实施（计划2026-11-01实施），且适用城市道路；不作为当前公路设施设计依据。[国家标准状态页](https://std.samr.gov.cn/gb/search/gbDetailed?id=511EBC5968749318E06397BE0A0AFBD5)
