## 对“门架双三角警告牌”的谨慎判断

仅凭“门架上有两个三角牌”的截图不能判定整体符合或违反国家标准。必须先确定每块牌的标准代号、表达的危险、服务的车道与来车方向、道路等级和事故/作业区场景，再核牌面尺寸、视认距离、设置位置、安装角度、路上方净空以及门架结构设计。门架是支撑形式之一，不会自动让其上的任意标志合规。

标准平台当前可核对GB 5768.2-2022的现行元信息，但本次未取得可读正文来确认4.4及4.8相关条文原文。因此本文不把“警告牌具体形状”“多牌数量上限”“警告标志组合限制”等二手摘录作为已核实要求。标准类别图标应与标准原图逐项核对；双警告牌需要在工程审核中说明各牌各自的警示对象和设置必要性，不能只看支撑形式或图标数量判断合规。

多警告牌的谨慎布设建议另有官方工程审查参考：[湖北省住建厅《湖北省房屋建筑和市政工程施工图审查常见问题汇编（2025年版）》通知及附件](https://zjt.hubei.gov.cn/zfxxgk/zc/qtzdgkwj/202504/t20250411_5612222.shtml)的交通设施相关内容提出警告标志不宜多设，同一地点需要两个以上时原则上只设其中最需要的一个（附件检索页码约119）。这是湖北省房屋市政工程施工图审查参考，不是GB 5768.2正文；标准条款原文和全国适用范围仍须以标准全文及项目所在地规定核对。产品界面可以据此给“同一地点多警告牌，请复核各自必要性”的非阻断提示，保留设计人员按项目条件继续配置的能力，不直接判为违规。

普通警告标志的颜色和图形应依GB 5768.2的具体标志图例判定。[官方公开工程设计说明](https://pdswgs.zfcg.henan.gov.cn/cmsweb81e27e/nas/webfile2024/sanmenxia/rootfiles/2025/09/18/e0b85d617048448fbd29b7e9b5be6135.pdf)依据GB 5768.2-2022描述普通警告标志采用黄底、黑边、黑图形；它是具体项目资料，不是国标原文。原占位图黑边不明显，现已增加独立的黑色三角边框并保留黄色内底与黑图案，单块双柱预览使用两柱支撑同牌的图例。上述修改改善类别辨识，不代表已按标准附图核定比例、色度、边框宽度或连接构造；白色衬边仍需逐项对标准图核验。

路侧标志高度与上跨道路净空是不同的设计问题。核查截图时应从GB 5768.2正文查对应标志位置、安装角度、高度和支撑形式条款，并依据道路建筑限界及工程设计核算门架下缘净空。本文没有读取标准全文，未给出条款号、净空值或牌面高度值。架体跨度、净空、基础、风荷载、疲劳与防撞等也不能从符号形状推断。

## 设施“怎么放”的产品规则

1. **先选依据和场景。** 至少记录道路类型（城市/公路）、道路等级、设计/运行速度、方向与进口道、主线/匝道、桥隧/平交、常态/作业区/事故管理区。标准引用保存标准号、版本、条款、适用条件和核查日期。没有条件就显示“待设计”，不要生成伪精确数值。
2. **把设施本体和支撑结构分开。** 标志面板是面状产品，柱脚/立杆和门架是支撑几何；门架跨越范围应记录跨度、方向、净空来源和关联车道。地图上的一个点只适合表达定位锚点，不代表完整门架或面板边界。
3. **布设依道路参照，而非符号屏幕朝向。** 标志应关联路线/里程、侧别或上方位置、适用行驶方向和目标车道，并保存面向来车的方向、偏角及视距校核。标线应按实际车道边界、中心线、停止线和导流区表达；不可把制图线宽解释为地面宽度。
4. **防护设施按风险和断面布设。** 护栏、端头、过渡段、中央隔离、防眩、隔离栅、声屏障、轮廓标等应从道路边缘、路侧危险、交通组成、净区、视距与连续性等工程条件推导。模型应支持端头/过渡段/缺口等对象，并记录设计依据；不得给所有道路自动套同一个高度、桩距或横向偏移。
5. **信号、照明、监控、通信、排水分别按系统设计。** 信号灯按进口道和信号组；照明按道路照明计算和配光；监控/检测按覆盖范围、杆件和电源通信条件；收费/通信设备按门架或路侧系统设计；雨水口、井、排水沟按汇水与管网。其位置不能由通用设施库推断，需关联专业图纸或设计输入。
6. **保留审核与来源。** 每个实例记录来源（标准/施工图/人工定位/影像推定）、标准版本及条款、确认人/状态、几何版本。冲突时提示并保留原输入，不能无提示覆盖人工布设。

## 逐类布设所需输入

下表是按设施功能整理的生产输入清单，供人工布设与后续规则建模使用，不是已实现的自动设计算法；未列统一间距、高度和默认支撑。

| 设施 | 应定位或关联的对象 | 布设前需要确认 |
| --- | --- | --- |
| 警告标志 | 危险位置前方、对应来车方向 | 危险类型、具体代码、速度与前置距离、视距 |
| 禁令、指示标志 | 限制或遵循开始位置、适用车道/进口道 | 起止范围、方向与辅助说明；告知与实际生效位置分别记录 |
| 指路标志 | 路口预告、决策点与确认位置 | 目的地、箭头、车道关系、信息连续性；多块牌不能仅复制同一模板 |
| 标线、突起路标 | 真实车道边界、停止线、导流区 | 类型、颜色、实虚线段、宽度与间隔，与交通组织一致 |
| 护栏、缓冲设施 | 路侧或中央危险范围、端头和开口 | 防护等级、变形空间、端头、过渡段与连接 |
| 轮廓标、诱导标 | 道路边缘、护栏、弯道等视线诱导位置 | 反光面朝向、线形与间距、安装载体 |
| 隔离栅、防落物网 | 公路边界或需要防护的跨越范围 | 出入口、结构连接、对象及范围；防落石网还需地形与落石风险 |
| 防眩、声屏障 | 中央分隔带或噪声敏感点相关路段 | 对向视线、视距、声学目标与安全空间 |
| 路灯 | 路侧、中央分隔带或独立照明区域 | 道路等级、配光、亮度/照度、均匀度、眩光与杆位 |
| 信号灯 | 进口道、停止线、人行过街和车道组 | 控制对象、相位方案、可见性与其他标志遮挡关系 |
| 监控、通信、收费 | 监测断面、覆盖区、收费车道或指定门架 | 覆盖范围、设备方向、通信电源、净空与结构条件 |
| 排水、井、控制箱 | 汇水低点、沟渠、管网或检修位置 | 标高、流向、连接、地下管线与维护空间 |

补充证据：已下载并核读[湖北官方修订附件](https://zjt.hubei.gov.cn/zfxxgk/zc/qtzdgkwj/202504/P020250910520743173556.pdf)的印刷第119页（PDF第124页），并渲染核对。本轮又直接核读GB 5768.2-2022第4.8.2—4.8.7条，确认多牌合杆数量、特殊组合限制与禁令/指示开始位置要求；详见分项报告。湖北指引仍只作为地方审图参考。

## 对当前模板的改进建议

当前目录位于[`tools/facility-assets/facility_catalog.py`](../tools/facility-assets/facility_catalog.py#L13)：它已明确说明分类不是全国设施总数，基础模板规格待填且不代表完成工程设计，这个边界应保留。目录为标志设置`sign_code`、面板宽高、支撑类型，为标线、防护设施设置一些规格字段；但缺少路线侧别、里程/方向、适用车道、安装角度、净空依据、设计速度/道路等级、风险场景、来源条款及核查状态等决定布设的输入。

当前[`tools/facility-assets/facility_support.py`](../tools/facility-assets/facility_support.py#L21)已有少量具体牌面的矢量图和类别占位图；`_CATEGORY_PANELS`的警告符号明确只是类别示意。支撑SVG中的`gantry`、`double_post`是图标形状，比例不表达工程尺寸；`support_defaults()`在无配置时回退到单柱示意默认。因此建议：

- UI把缺省“单柱示意”显示为未确认的预览状态，导出属性仍为空；避免把示意默认当成设计决定。
- 以标准编号/标准图版本关联面板图形；扩展具体警告标志代码，类别文字、图形和尺寸分别受校核，不用“注意危险”一个牌覆盖所有告警。
- 将多个牌面与单块牌内分区区分；`panel_count`上限是数据结构校验值，不代表规范允许的合杆数量或具体多牌组合。
- 增加“布设状态/所需资料”校验：只有道路场景、标志代码、位置和方向齐备时才显示规则结果；缺失净空/支撑结构计算时明确标注“仅位置示意”。
- 把`SIGN_SOURCE`更新为国家标准平台中可读的正式标准条目和适用版本，并单独记录第1号修改单、GB 5768.9-2025等场景性依据；其他设施的来源字段也要指向各自领域文件，不能用一个安全设施通用链接代替。

## 尚待核对

- 继续读取GB 5768.2其他图形、制作附图、第1号修改单以及JTG D82正文，建立可执行条款数据。第4.8.2、4.8.5、4.8.9—4.8.12条已经核读；第4.4和每个具体标志的完整制作图仍未逐图复核。

- 当前类别跨越公路和城市道路、固定设施与临时交通管理设施。应逐个子类补全当地适用标准和专业设计依据；此清单不是设施全生命周期设计规范汇编。
