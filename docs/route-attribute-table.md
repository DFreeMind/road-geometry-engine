# 路线属性表与条件筛选

读取多条路线后，选择窗口以属性表显示数据：每条要素一行，每个业务字段一列。默认显示全部业务字段，支持横向滚动、固定表头和选择列；字段注释显示在表头下方，完整值可通过单元格悬停查看。通过“显示字段”搜索名称或注释并勾选列，隐藏列不删除源属性，也不影响筛选。

每页最多显示 50 条记录。单条复选、全选筛选结果及清空选择支持跨页；改变本地筛选条件保留已选记录，已选数量可能超过当前匹配数量。点击“加载到地图”会创建可见的源路线图层，保留完整多部件几何、属性与字段注释，并自动定位。多选不再只是缩小候选集合；单击地图上的源路线可设为当前生成参考线。活动参考线可单独生成；参与生成的来源路线可使用“生成全部参与路线”分块生成，见 [批量生成](source-batch-generation.md)。

## 筛选方式

快速筛选对指定字段或全部字段执行不区分大小写的文本包含查询。

“表达式筛选”接受 WHERE 条件表达式，点击“应用条件”或 Ctrl+Enter 生效。字段名可用双引号，文本值用单引号；字符串中单引号用两个单引号转义。错误条件会报告位置并保留之前有效的结果。

```sql
left("route_id", 3) = 'G10' AND right("route_id", 2) IN ('01', '02')
"name" ILIKE '%环线%' AND "lanes" >= 2
"width" IS NULL OR coalesce("width", 0) < 7
```

支持 left、right、lower、upper、trim、length、coalesce 函数，以及比较、AND / OR / NOT、括号、LIKE / ILIKE、IN 和 IS NULL 条件。left / right 按 Unicode 字符处理，负数长度采用 PostgreSQL 的截取含义；NULL 条件采用三值逻辑，只有结果明确为真才匹配。函数语义参考 [PostgreSQL 字符串函数](https://www.postgresql.org/docs/current/functions-string.html)。本地大小写与文本比较不使用数据库服务器的排序规则。

下方“表达式筛选”在本地已加载批次中执行，支持文件与数据库来源。“数据源筛选条件”则由适配层查询整个来源，二者作用范围分别标注。它不是完整 SQL，不执行 SELECT、JOIN 或数据库写入。表达式通过明确的解析器执行，未知字段、函数及无效语法均显示错误。

## 数据库读取和大数据

连接区的常态操作为选择连接、选择路线图层和“打开路线数据”。管理、认证、目录刷新和手动登记放在“连接操作”，PostGIS 条件、批量大小及当前地图范围放在“读取范围”。

文件、GeoPackage/SQLite 与 PostGIS 统一默认每批 500 条，可设置 100、500、2,000、10,000 条。来源条件在 LIMIT 前执行，可搜索原先前 2,000 条之外的数据。路线选择器对可分页来源默认继续读取到末页，支持停止和继续；传输批次与表格展示页分开，跨页选择保留，重新应用不同来源条件会清空选择。没有整体 10,000 条选择上限；每批最多 10,000 条是传输保护。“还有更多”表示后续批次存在，不代表全表读取完毕。其他尚未适配的连接明确标记为有界快照，不能在快照中假装对整个来源查询。第一阶段范围见 [来源无关改造计划](source-neutral-data-access-plan.md)。

数据库条件采用同一组常用函数与操作符的白名单解析，字符串与字段引用重新编码，拒绝多语句、子查询、未知函数和注释。数据库比较实际遵循服务器的类型及排序规则，本地筛选不能保证与服务器所有类型行为一致。

读取采用 LIMIT+1 判断是否有下一批，不运行全表 COUNT。存在主键时按主键排序，无主键时显示分页稳定性警告，静态表也不能保证顺序；不同请求不是事务快照，表被修改时可能重复或遗漏。当前使用 OFFSET，深分页仍可能变慢；大表优先用业务条件与地图范围缩小结果，不宣称无限数据量都能快速加载。参见 [PostgreSQL LIMIT/OFFSET 官方说明](https://www.postgresql.org/docs/current/queries-limit.html)。

“当前地图范围”是 WGS84 包围盒，后端转换到选中几何列的 CRS，使用空间包围盒相交条件，不转换整表几何来筛选。[PostGIS 包围盒操作可利用已有空间索引](https://postgis.net/docs/geometry_overlaps.html)，但本轮不会自动修改用户数据库。地图显示副本只包含几何和定位索引，原始属性保留在工程中；未变化图层不会在每次视图更新时重复 setData。属性表每次只渲染 50 行，全文检索缓存当前批次的文本。

超大路线网的矢量瓦片、服务端游标/键集分页及多路线批量几何生成尚未实现；高顶点数和庞大工程的存储/撤销开销仍需专门实测，当前分批上限不是性能保证。源图层保留 MultiLineString 全部部件，但活动参考线沿用现有最长连续段选择逻辑，复杂多部件路线需另行明确业务上的连续参考线，不能把地图显示的全部部件理解为已参与生成。
