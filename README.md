# Road Geometry Engine · 道路几何工作台

设施分类、规格管理与独立客户端方案见 [设施与地图架构](docs/facility-and-map-architecture.md)。正式客户端目标是不要求用户安装 QGIS，优先验证 Rust + Tauri + OpenLayers，MapLibre 做对照；当前原型尚未完成迁移或独立打包。

本地桌面原型：连接路线数据、添加影像或在线底图、映射属性字段或手绘路线，设置左右横断面，调用 Rust 引擎生成车道、隔离带、应急车道、路肩和边坡水平投影，再导出空间成果。

## 快速启动

当前原型复用本机 QGIS 3.44 的 Qt/PyQGIS 运行环境，不需要打开 QGIS 主程序。它尚不是可脱离 QGIS 安装运行的独立发行包。

「道路 → 设施库管理」提供 12 个产品分类、66 个基础子类型模板，支持搜索、复制/编辑自定义、导入/导出 JSON。三栏管理界面按系统、自建/旧模板、上传导入组织，支持类别筛选、预览、规格表单与折叠高级编辑。「手动放置」侧栏选择大类后列出小类，点击模板或按 Enter 直接进入地图放置；支持点、两端点线及多边形区域，保存和导出保留模板版本与规格快照。「已放置设施」单独折叠管理。「管理设施库」可就地打开库管理。交通标志使用牌面与支撑组合图形，可选单柱、双柱、单悬臂、门架和附着式，点击位置对齐支撑落地点，牌外背景透明；门架、双柱和悬臂可用两点定义平面跨杆，按米制跨度随地图缩放；支撑与未确定的安装高度随实例保存，不冒充工程设计。具体标志图例及类别示意的范围见 [图例依据](docs/sign-symbol-reference.md)。可导入 `fixtures/facility-template-example.json` 查看照明规格与交错规则示例；演示参数不是规范推荐值。图形附件上传和专业自动布设规则执行属于后续范围。

前提：Windows、QGIS 3.44、Rust stable/MSVC 构建环境。当前验证环境是 QGIS 3.44.8 与 Rust 1.96.1。启动脚本优先读取 `ROAD_QGIS_ROOT`，否则搜索 Program Files 下的 QGIS 安装。

双击根目录 `start.cmd`，或在 PowerShell 中运行：

```powershell
.\launch.ps1
```

桌面窗口默认最大化，支持 Windows 系统显示缩放。「工程属性」和「地图图层」为可停靠面板，默认在左侧以标签切换；可拖动边界调整宽度、拖动标题浮动或移到另一侧，也可通过「视图」菜单隐藏和恢复。字段映射表单支持滚动，底部确认操作保持可见。

默认使用 release 引擎；首次启动时如无二进制文件会构建。修改 Rust 源码后需重新构建：

```powershell
cargo build --release --locked
.\launch.ps1 -Foreground
```

指定 QGIS 安装位置：

```powershell
.\launch.ps1 -QgisRoot 'C:\Program Files\QGIS 3.44.8'
```

## 第一轮验证

顶部集中连接数据与保存项目，打开项目及演示入口收在菜单中。地图直接占据主视区：左上浮层切换底图，展开显示设置后调整透明度和坐标适配；左侧使用统一线条图标进行地图操作；右上图例可折叠；左下显示比例尺与坐标，右下显示底图署名链接。左侧按数据、字段映射、横断面、路面与设施组织，底部使用单行指标、生成、取消和导出菜单。应用默认最大化并按系统 DPI 显示，验证覆盖 1024×720 和 1280×800 窗口。

底图下拉框可快速选择 OSM 街道、NASA GIBS 卫星区域背景、Esri 公开卫星、Clarity 影像、地形晕渲、开发者卫星服务、高德街道和卫星及已加载的本地/自定义底图。切换复用已加载图层、保持工程范围，底图互斥显示，支持不透明度与“无底图”。NASA MODIS 分辨率 250m，默认日期两天前，仅在 1:250,000 及更小比例尺显示，可能有云或缺测，不能用于识别车道。Esri 公开浏览入口无需填写令牌；开发者服务需要 URL 安全访问令牌，令牌仅驻留会话。公开浏览不等于开源或无限制免费使用。OSM 本身不提供卫星底图，编辑器中的航空/卫星影像来自第三方。

高德街道与卫星使用内置公开浏览瓦片地址，无需手动填写密钥；已在实际客户端中读取并显示两类瓦片。初次选择国内底图默认开启近似 GCJ-02 显示适配，可在地图浮层「显示设置」关闭，当前会话记住每个底图的选择；切换坐标体系时保持对应的地理视点。公开可访问不代表无限制使用或开源许可。自定义 XYZ 也可明确选择 WGS84 / Web Mercator 或国内 GCJ-02 网格。适配仅改变工程矢量的显示副本，原始路线、计量、保存和导出保持原坐标，绘制点反算为原始坐标。它不能替代官方转换或测绘校核；不处理 BD-09、复杂边界及全球精确转换。适配副本仍在界面线程构建，当前仅验证有界原型样本，大路网应先增加后台构建与增量缓存。

服务说明：[OSM 瓦片政策](https://operations.osmfoundation.org/policies/tiles/)、[NASA GIBS](https://nasa-gibs.github.io/gibs-api-docs/access-basics/)、[Esri 官方服务](https://developers.arcgis.com/rest/basemap-styles/service-data/)、[高德坐标体系](https://lbs.amap.com/api/javascript-api-v2/guide/abc/basetype)。程序显示来源链接，在线数据只用于视口浏览，不提供预取或批量下载；网络、覆盖范围和账户权限影响瓦片是否可用。

地图工具条提供平移、放大、缩小及当前比例尺，状态栏显示项目坐标。地图获得焦点时按 `F` 适配路线、`P` 切换平移；`F5` 生成，`Ctrl+S` 保存项目，`Ctrl+O` 打开项目。绘制时左键加点、`Backspace` 撤销上一点、`Enter` 或右键完成、`Esc` 取消；切回平移也会取消未完成草图。图层可勾选显隐和定位，底图可移除且保留源文件；在线底图定位以当前路线为范围。底图配置随内容调整高度，错误直接显示在表单内，必需输入有效后才允许添加。

- **连接数据**：选择本地 GeoJSON / SHP / GeoPackage，或填写 WFS / PostGIS 连接信息。读取完成后，可切换路线要素；当前采用最多 2,000 条路线的有界快照，每次生成所选的一条路线。远程连接配置已验证，真实服务连通性需要用实际服务器验证。
- **字段映射**：点击「配置字段映射」，选择路线 ID、左右车道数及宽度、隔离带、应急车道、路肩和边坡投影字段。表格显示当前要素的字段值；未映射参数使用横断面页的手动值。映射空值默认报错，只有明确启用回退才使用手动值；无效数值不能静默替代。
- **底图**：在线入口提供 OpenStreetMap、自定义 XYZ、WMS；文件入口支持已定位的 GeoTIFF、VRT、IMG、JPEG/PNG，以及 SHP、GeoJSON、GeoPackage 矢量底图。图片须具备有效 CRS 和地理参考；普通未定位截图仍须先配准。矢量底图的显示线宽不会用于道路宽度推导。
- **路面与设施**：选择沥青 / 柏油、混凝土或碎石；默认采用铺装颜色及米制宽度标线，也可切换彩色组成图检查横断面。材质是成果属性和地图样式，不改变道路几何，不代表材料检测或施工结构设计。
- **沿线设施**：可选护栏、轮廓标、照明、标志、里程牌和道路标线，设置间距、左右侧及距铺装外缘的附加偏移。设施为参数化示意成果，`source=parameter_template`、`confirmed=false`；`station_m` 为参考线几何累计长度，不是带断链的业务桩号。标志图形是通用示意，不代表已经确定的标志版面。
- **保存和导出**：保存路线、离线属性快照、字段映射、手动值、材质/设施选项及本地底图路径、选择与不透明度。数据库密码、令牌与连接 URI 不写入项目；重新打开项目不会主动连接在线底图，需要重新选择在线服务和重连远程源。GeoPackage 分层导出道路面、标线和各类设施；GeoJSON 将这些成果合为 WGS84 要素集合，保留材质、设施类型与来源。

1. 普通启动载入真实 OSM 西长安街参考线与高德卫星图，并生成模板路面；通过图例中的眼睛按钮对比底图、在「路面与设施」调整成果不透明度。线几何是真实 OSM 数据，宽度为待确认人工模板。合成弯道仍可从数据菜单选择，烟雾测试使用合成样本。
2. 修改左右车道数量及宽度，重新生成，确认不对称布局；左右按路线顶点顺序定义。
3. 导入 `fixtures/sample-route.geojson`，验证 WGS84 路线到本地 UTM 的转换。
4. 加载自己的已配准 GeoTIFF；或运行完整验证脚本生成 `artifacts/fixtures/test-basemap.tif`，加载该栅格并叠加内置路线。该栅格为合成测试网格，不是卫星影像。
5. 使用「绘制参考线」在底图上描绘道路参考线，再按横断面生成道路面。它不是道路边界勾画或影像识别工具：左键增加顶点，Backspace / Delete / Ctrl+Z 删除最后一点，Enter、右键或模式条「完成」结束；Esc /「取消」保留原路线。完成后替换原路线，可撤销。
6. 导出 GeoPackage 和 GeoJSON，重新用 GIS 软件加载，对比位置、断面与属性。
7. 保存并重新加载项目 JSON，验证输入路线与横断面恢复。
8. 「路面与设施」分为「手动放置」「沿线自动」「路面显示」。手动页选择类型、点击「开始放置」后在地图定位；护栏依次选择起点、终点，默认完成一项返回平移，可勾选连续放置。Esc / 右键先取消护栏起点，再次退出。表格选择后删除、双击定位。自动页先生成路面，再调整设施、点间距、左右侧和偏移，点击「应用沿线布设」提交；未应用参数不进入保存或导出。「还原参数」放弃草稿，「清除自动设施」保留手动设施和道路标线，可撤销。道路标线及材质归入路面显示页；导出后检查 `facility_type`、`confirmed` 和材质字段。

路线与断面发生变化后，旧成果不再作为当前成果导出；需要重新生成。在线 OSM 底图仅由用户主动启用。普通启动示例会请求高德卫星视口瓦片；网络不可用时仍可生成和导出，离线生产可选择无底图或文件底图。

## 操作闭环

- **清除底图**：数据页图层区一键清除全部底图；每个底图行的「×」只移除该底图，保留文件。清除正在添加的底图也会取消加载，不允许迟到的回调重新添加。
- **删除路线**：路线 ID 旁的删除按钮、参考线图层行「×」或数据菜单删除路线；同时清除其成果，保留底图。完成的手绘线可删除。地图获得焦点时按 Delete 可删除路线；绘制中用 Backspace 删除最后一点。
- **撤销**：编辑菜单或成果页撤销按钮恢复上一项路线编辑或成果清除，保留最多 20 项内存历史；地图焦点时 Ctrl+Z。绘制过程中撤销最后一个草图点，编辑文本时沿用文本框自己的撤销。
- **对比**：地图右上图例眼睛按钮临时隐藏路线、路面与设施，再点击恢复；比较期间切换底图也能正确恢复显示状态。成果不透明度独立于底图不透明度。
- **重新开始**：可载入真实示例、连接其它路线或绘制新线。替换路线时旧成果不可继续导出；删除、清除、重新生成可连续操作。空路线项目可保存并重开；打开项目清除上一项目成果，需按恢复的输入重新生成。
- **手动设施**：位置存储在工程米制坐标中，国内底图适配时反算到原始坐标。每项保留放置时的路线归属，切换路线不重新绑定；更换工程 CRS 会转换位置。手动设施不因清除道路成果、删除路线或重新生成而被覆盖，通过表格删除，可撤销。项目会保存并恢复手动设施；打开新项目替换上一项目的手动设施。
- **设施显示与导出**：标志、路灯、里程牌和轮廓标使用不同的矢量符号，护栏显示梁与立柱。点符号采用屏幕单位保证辨识，`symbol_is_schematic=true` 不表示实际设施大小；手动位置记录 `source=manual_placement`、`confirmed=false`，需要现场或影像核验。GeoPackage 使用 `manual_*` 图层，与参数模板的 `road_*` 图层区分；只有手动设施而没有道路时也可导出。
- **材质和符号**：沥青、混凝土与碎石使用轻量 SVG 材质显示，车道间不再用黑边割裂路面，边界由实际标线展示。纹理只是制图样式，不代表影像恢复的表面状况。模板设施的同桩位置图标按类型作屏幕偏移以减少遮挡，导出几何仍保持参数位置；手动设施符号不作此偏移。手动护栏段上限为 100 km，拒绝重复端点与非有限坐标。
- **桌面布局**：标准菜单栏提供完整命令，紧凑图标工具栏集中项目、绘制、设施、撤销和删除操作。工程属性与图层面板可停靠、浮动或隐藏，地图右上图例提供底图对比。固定高度的底部指标栏随可用宽度显示主要指标，悬停查看完整指标，避免内容变化导致地图视口跳动。
- **实时绘制**：参考线已点击的节点用实线显示，鼠标所在的待定末段用虚线显示；光标旁显示本段与总长度，按原始工程米制坐标计量。鼠标移动只更新覆盖物，不重新渲染底图、不写入路线。Backspace 撤回节点、Enter / 右键完成、Esc 取消；完成草图保持视点，需缩放到全幅时点击适配范围。
- **连续刷新**：删除路线及成果时保留底图和手动设施，不先清空全部画布图层；批量替换期间保留上一帧，结束后统一刷新，启用 QGIS 图层图像缓存。离线验证覆盖删除过程中的图层列表、视点和帧采样；大影像及不同显卡/DPI 下仍需专门评估。
- **底图平移**：慢速瓦片加载期间保留已加载画面，视口渲染完成后更新，显示加载状态；不主动预取邻接视口。650 ms 延迟的本地瓦片服务覆盖连续平移的重叠区域帧采样，新区域仍需等待实际瓦片返回。

真实示例来源、单向车行道参考线性质及许可见 `fixtures/real-route.md`。真实路线不意味着已取得实测路面宽度；示例使用 7 米人工模板，并非西长安街全幅宽度。道路成果导出保留几何来源 URL、许可及参考线性质，地图同时展示 OSM 路线署名。

完整离线流程纳入 `scripts/validate.ps1`。在实际网络中检查高德街道、卫星和真实路线叠加：初始化 `scripts/qgis-env.ps1` 后运行 `tests/client_workflow.py --online`，报告和截图位于 `artifacts/real-map-qa/`。这验证实际瓦片显示与坐标存储隔离，不代表道路宽度或测绘精度验收。

## 当前限制

- 首版处理单条连续路线、固定横断面；客户端每一侧车道暂采用相同宽度，Rust 接口支持逐车道宽度数组。
- 源路线必须有有效 CRS；客户端转换为适合局部区域的 UTM 米制坐标。跨区域、极区和复杂分区数据需单独处理。
- 连接数据源后可选择一条路线进行生成；不连续的多部件输入不能隐式合并。
- 普通弯道采用共享偏移边界和受限 miter 转角；自交、折返或不适合当前算法的急弯会报错。
- 缺属性时使用人工模板；生成结果是参数推导成果，不自动代表实测道路边界。
- `paved_width_m` 为车道、应急车道与路肩宽度总和；`platform_width_m` 另包含中央隔离带；`total_width_m` 再包含边坡水平投影。
- 当前没有影像道路识别、截图配准、沿线变宽、交叉口连接、立交关系或真实地形边坡能力。
- 单次输入顶点上限由引擎定义；首版几何检查包含二次复杂度环节，不把小样本耗时作为大路网性能保证。
- 界面调用 Rust 采用异步进程并支持取消；矢量数据连接采用后台任务及有界快照；底图初始化同样采用后台任务；项目恢复与成果导出仍需后续完善后台 I/O 与大数据性能。

## 架构

```text
Qt / PyQGIS 独立桌面窗口
  ├─ QGIS 地图画布、栅格/矢量、坐标转换
  ├─ 路线与断面编辑、项目文件、导出
  └─ QProcess 异步 JSON 协议
       └─ Rust 道路几何引擎
            ├─ 输入校验与横断面规则
            ├─ 共享偏移边界及面生成
            └─ 自交、面积与重叠检查
```

界面使用 Python 组织控件与调用原生 QGIS 能力，业务几何在 Rust 中实现。核心不依赖 UI；后续可替换桥接方式和客户端界面，无需重写道路规则。

`src/main.rs`：引擎及单元测试。`desktop/main.py`：桌面应用。`tests/engine_integration.py`：使用 QGIS/GEOS 独立校验 Rust 输出。`launch.ps1`：启动入口。`AGENTS.md`：项目协作规则。
